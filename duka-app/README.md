# Duka System

A small-business sales and inventory system built with React + Vite.

## Phase 2

This version focuses on the frontend experience:
- redesigned dashboard
- improved POS / sales workflow
- product and stock management UI
- expense tracking UI
- reports and business insights
- owner vs sales-staff views
- responsive layout and reusable UI patterns
- Supabase foundation retained for Phase 3

## Run locally

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Supabase

Supabase is not connected to live data yet. The schema and client foundation are included so Phase 3 can move the local demo data to PostgreSQL + Auth + Row Level Security.
